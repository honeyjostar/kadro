# Каталог плагинов Kadro

Переходы и эффекты сообщества. В Kadro: `Настройки` → `Плагины` → **Каталог плагинов** — живое превью и
установка в один щелчок.

- `transitions/` — переходы (`vec4 transition(vec2 uv)`, формат [gl-transitions](https://gl-transitions.com))
- `effects/` — эффекты (`vec4 effect(vec2 uv)`)
- `index.json` — список для Kadro: названия, описания, SHA-256 файлов. Собирается командой `npm run plugins:index`.

Как написать свой плагин и прислать его сюда — в [docs/PLUGINS.md](../docs/PLUGINS.md#поделиться-и-прислать-в-каталог).
Все плагины в этой папке — под лицензией, указанной в заголовке файла (встроенные — MIT).
