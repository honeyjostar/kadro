# Своё оформление Kadro

Вид Kadro можно менять двумя способами.

- **Настройки** — шестерёнка на главном экране или вверху справа. Там тема (тёмная, светлая, как в Windows),
  цвет акцента (розовый, фиолетовый, синий, чёрно-белый), значок программы (чёрный, белый, розовый, фиолетовый,
  синий или своя картинка) и размер интерфейса (90–125%).
- **Своё оформление** — для тех, кому мало готового: свои цвета, шрифты, скругления, фон, размеры элементов.
  Это обычный CSS, как у сайта. Ниже — как им пользоваться.

## Как включить

1. Kadro → **Настройки** → раздел «Своё оформление» → **Открыть папку оформления**.
   Откроется папка `%USERPROFILE%\.kadro\custom` (например, `C:\Users\Имя\.kadro\custom`) с тремя файлами:
   - `theme.json` — цвета и размеры (переменные оформления);
   - `custom.css` — любые стили;
   - `README.txt` — краткая памятка.
2. Включи переключатель **«Подключить мои стили»**.
3. Открой файл в Блокноте (или VS Code), поменяй, сохрани — Kadro применит изменения **сразу**, перезапускать не нужно.

Сломал вид — выключи переключатель в настройках. Если не видно даже настроек — переименуй `custom.css`
и `theme.json` (например, в `custom.css.off`) — Kadro подхватит это сразу.

Значок программы меняется в разделе «Значок программы»: у окна, ярлыков на рабочем столе, в меню «Пуск» и на панели задач.
Если на рабочем столе остался старый значок — нажми на рабочем столе F5 (Windows иногда показывает значок из кэша).

## theme.json — цвета

```json
{
  "dark":  { "--accent": "#00d1c1", "--bg": "#0c1118", "--panel": "#121a24" },
  "light": { "--accent": "#007f75" },
  "all":   { "--radius-s": "8px", "--radius-m": "14px" }
}
```

- `dark` — для тёмной темы, `light` — для светлой, `all` — для обеих.
- Ключ — переменная, значение — любой цвет или размер CSS: `#ff8800`, `rgb(20 30 40)`, `12px`.
- Ключи, которые начинаются с `_`, — комментарии (например, `"_help"`).
- Ошибка в файле (лишняя запятая, кавычки) — Kadro покажет сообщение, остальное оформление продолжит работать.

| Переменная | Что красит |
|---|---|
| `--bg` | фон окна |
| `--panel` | фон панелей (слева, справа, таймлайн) |
| `--raised`, `--raised-2` | кнопки, плитки, поля |
| `--line`, `--line-soft` | рамки и разделители |
| `--text`, `--muted`, `--faint` | основной, второстепенный и бледный текст |
| `--accent` | акцент: главные кнопки, курсор таймлайна, выделение |
| `--on-accent` | текст на кнопке с акцентом |
| `--accent-soft` | полупрозрачная подсветка выделенного |
| `--accent-ink` | текст на выбранных «чипсах» |
| `--video`, `--overlay`, `--audio`, `--textclip`, `--caption` | клипы на таймлайне: видео, наложения, звук, текст, субтитры |
| `--audio-wave` | форма звуковой волны |
| `--radius-s`, `--radius-m` | скругления: мелких элементов и панелей |
| `--font` | шрифт интерфейса |
| `--logo` | шрифт логотипа и крупных заголовков |

## custom.css — всё остальное

Любые правила CSS. Несколько готовых:

```css
/* шрифт интерфейса — любой, установленный в Windows */
body { font-family: 'Segoe UI', sans-serif; }

/* картинка на главном экране */
.home { background: url('file:///C:/Users/Имя/Pictures/bg.jpg') center / cover; }

/* панели полупрозрачные поверх картинки */
.home-format, .recent-card, .home-tpl { backdrop-filter: blur(8px); background: rgb(20 18 26 / 0.7); }

/* таймлайн: клипы круглее, подписи крупнее */
.clip { border-radius: 10px; }
.clip-label { font-size: 13px; }

/* спрятать подсказки */
.hint { display: none; }
```

Как узнать класс нужного элемента: нажми **F12** в окне Kadro — откроются инструменты разработчика
(как в Chrome). Кнопка со стрелкой в левом верхнем углу → наведи на элемент → справа видно его класс и стили.
Там же можно пробовать правила вживую, а удачные — переносить в `custom.css`.

## Что можно и что нельзя

- Можно: цвета, шрифты, размеры, отступы, фон, прозрачность, анимации CSS, спрятать лишнее.
- Скрипты (JavaScript) не подключаются — только оформление. Так чужая «тема» из интернета не сможет ничего
  сделать с твоими файлами.
- Оформление хранится в папке данных и переживает обновления Kadro.

## Поделиться оформлением

Отправь другу два файла — `theme.json` и `custom.css`. Он кладёт их в свою папку оформления
(Настройки → Открыть папку оформления) и включает переключатель.
