# Kadro 1.0 — план большого обновления

Всё копится в ветке `kadro-1.0` и выходит **одним выпуском 1.0.0**. Пока выпуска нет, в `master` (и к пользователям)
отсюда ничего не уходит. Отметки: `[x]` — готово в ветке, `[~]` — в работе, `[ ]` — ещё не начато.
Часы — оценка работы вместе с тестами.

## Главное

- [~] **Субтитры как у блогеров** — 3–4 ч.
  Стили «Хормози», «MrBeast», «По слову», «Плашка», «Неон», «Караоке». В субтитре 1, 2, 3 слова или строка.
  Ключевые слова — цветом, эмодзи по смыслу над субтитром, «выскакивание». Код уже есть, осталось проверить
  в работе и написать тесты.
- [ ] **Нарезка длинного видео в шортсы** — 6–8 ч.
  Стрим, подкаст или влог → распознавание речи → лучшие моменты (крючок в начале, цельные фразы, эмоции,
  плотность речи, громкость) → список с таймкодами → вертикальные проекты: кадр следует за человеком, субтитры
  как у блогеров, заголовок-крючок.

## Своё, уникальное

  Распознавание → перевод → озвучка по тем же таймингам, без интернета, например русский → английский.

- [ ] **Мем-кнопки** — 4–5 ч.
  Драматический зум со звуком, «Продолжение следует…» со стоп-кадром, басс-буст с тряской, замедление с «бум».
  Свои рисунки и бесплатные звуки, без чужих логотипов.
- [ ] **Форматы для русских площадок** — 3–4 ч.
  «Кружок» Telegram (круглое 640×640, до 60 с), ВК Клипы, RuTube, Дзен — с их зонами интерфейса.
- [ ] **Монтаж словами** — 5–6 ч.
  «Убери паузы, субтитры как у Хормози, музыку тише» → Kadro делает. Без интернета, на заранее заданных командах.

## Заставка при запуске

- [ ] **Анимация входа в Kadro** — 3–4 ч.
  При запуске: рабочий стол со значком Kadro, мышка подлетает, двойной щелчок, и значок раскрывается в окно
  программы, на главный экран. Длится 1–1,5 с и идёт, пока программа загружается, так что запуск не замедляет.
  Щелчок или любая клавиша — пропустить. Значок — того цвета, что выбран в настройках.
  - «Настройки» → «Оформление» → «Заставка при запуске»: вкл/выкл.
  - Слабый компьютер (мало потоков процессора или памяти, видеокарта не рисует) — после первого показа Kadro
    предложит: «Компьютер не самый быстрый — выключить заставку?».
  - Включено «Уменьшить движение» в Windows — заставка выключена сразу.

- Звуки, музыка и картинки — только с лицензией, разрешающей встраивать в программу (CC0, Mixkit в составе

- Всё ИИ — на компьютере пользователя, без интернета после скачивания моделей.
- Никаких клонов чужих голосов.
