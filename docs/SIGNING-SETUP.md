# Подпись Kadro (SignPath) — что сделать после одобрения

Подпись убирает окно Windows «Система Windows защитила ваш компьютер» при установке Kadro.
Сборка уже готова: как только в настройках репозитория появятся значения ниже, следующие выпуски подписываются сами.
Пока их нет — всё собирается как раньше, без подписи.

## Один раз

1. **SignPath** (письмо об одобрении → вход в app.signpath.io):
   - в проекте Kadro → *Artifact Configurations* → конфигурация по умолчанию → вставить текст из
     [`.signpath/artifact-configuration.xml`](../.signpath/artifact-configuration.xml) и сохранить;
   - проверить, что к проекту подключён *Trusted Build System* «GitHub.com» (обычно его подключает SignPath Foundation);
   - запомнить: **Organization ID** (в настройках организации), **slug проекта** и **slug политики подписи**
     (обычно `Kadro` и `release-signing`);
   - создать **API-токен** пользователя с правом *Submitter* в этом проекте и политике.
2. **GitHub** → репозиторий Kadro → *Settings* → *Secrets and variables* → *Actions*:
   - вкладка *Secrets* → *New repository secret*: имя `SIGNPATH_API_TOKEN`, значение — API-токен;
   - вкладка *Variables* → *New repository variable*: `SIGNPATH_ORGANIZATION_ID` — Organization ID;
   - только если slug отличаются от `Kadro` и `release-signing`: переменные `SIGNPATH_PROJECT_SLUG`, `SIGNPATH_SIGNING_POLICY`.

Токен вставляется только в GitHub Secrets — никому его не пересылать и не писать в чаты.

## На каждый выпуск

Сборка отправляет на подпись два файла по очереди и ждёт подтверждения (до двух часов каждый):

1. `Kadro.exe` — программа (до упаковки в установщик);
2. `Kadro-Setup-X.Y.Z.exe` — установщик.

От SignPath придут две заявки — подтвердить обе (вторая появится через пару минут после первой).
Не подтвердили за два часа или отказали — выпуск всё равно выйдет, но без подписи (в сборке будет предупреждение).

Проверить подпись: правой кнопкой по установщику → *Свойства* → вкладка *Цифровые подписи*.

Обновления внутри Kadro окна Windows не вызывают и без подписи — скачанный самой программой файл Windows не помечает.

Ручной запуск (Actions → Release → Run workflow) подписывает, только если отметить «Подписать через SignPath».
