## Kadro 0.7.0

### ⬇ Скачать / Download

- **[Kadro-Setup-0.7.0.exe](https://github.com/honeyjostar/kadro/releases/download/v0.7.0/Kadro-Setup-0.7.0.exe)** — установщик, около 212 МБ (после установки около 700 МБ). Рекомендуется. / Installer, recommended.
- [Kadro-0.7.0-portable.zip](https://github.com/honeyjostar/kadro/releases/download/v0.7.0/Kadro-0.7.0-portable.zip) — без установки, около 292 МБ: распакуй и запусти `Kadro.exe`. / Portable: unpack and run `Kadro.exe`.

Kadro 0.6.0 обновится сам: появится «Вышел Kadro 0.7.0» → «Обновить». Со старых версий — поставь установщик поверх, проекты и настройки сохранятся.

Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее → Выполнить в любом случае» (у установщика нет платной подписи).

### Новое
- **Английский интерфейс.** Все меню, подсказки, сообщения, названия эффектов, переходов, шаблонов и плагинов каталога — по-английски. «Настройки» → «Язык · Language»; при первом запуске язык берётся из Windows. Переводы лежат в одном файле — [src/shared/i18n/en.json](https://github.com/honeyjostar/kadro/blob/master/src/shared/i18n/en.json), правки приветствуются.
- **Установщик на двух языках** — выбирает язык Windows сам.
- Страница проекта по-английски — [README.en.md](https://github.com/honeyjostar/kadro/blob/master/README.en.md).

### New in English
- **English interface.** Every menu, hint and message, plus the names of effects, transitions, templates and catalog plugins. Switch in **Settings → Language**; on first run Kadro follows your Windows language. All strings live in [src/shared/i18n/en.json](https://github.com/honeyjostar/kadro/blob/master/src/shared/i18n/en.json) — improvements are welcome.
- **Bilingual installer** that follows your Windows language.
- An English project page — [README.en.md](https://github.com/honeyjostar/kadro/blob/master/README.en.md).

В 0.6.0 — автообновление, перевод субтитров без интернета, маркеры и главы для YouTube, каталог плагинов, «Сообщить об ошибке». Полный список возможностей — в [README](https://github.com/honeyjostar/kadro#readme).
