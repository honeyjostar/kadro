## Kadro 0.6.0

### ⬇ Скачать

- **[Kadro-Setup-0.6.0.exe](https://github.com/honeyjostar/kadro/releases/download/v0.6.0/Kadro-Setup-0.6.0.exe)** — установщик, около 212 МБ (после установки около 700 МБ). Рекомендуется.
- [Kadro-0.6.0-portable.zip](https://github.com/honeyjostar/kadro/releases/download/v0.6.0/Kadro-0.6.0-portable.zip) — без установки, около 292 МБ: распакуй и запусти `Kadro.exe`.

«Source code» в списке файлов ниже — исходный код для программистов, программы там нет. `SHA256SUMS.txt` — контрольные суммы файлов.

Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее → Выполнить в любом случае» (у установщика нет платной подписи). Обновление ставится поверх, проекты и настройки сохраняются. **Это последний раз, когда обновлять нужно вручную:** начиная с 0.6.0 установленный Kadro обновляется сам.

### Новое
- **Автообновление.** Kadro сам проверяет, нет ли новой версии, и показывает «Вышел Kadro X»: «Что нового», «Обновить» — установщик скачивается, сверяется по контрольной сумме и ставится без лишних вопросов, Kadro открывается уже новым. Проект сохраняется. В «Настройках» → «Обновления» — проверить вручную или выключить проверку.
- **Перевод субтитров без интернета.** Раздел «Субтитры» → «Перевод субтитров»: с русского, украинского, немецкого, испанского, французского, итальянского, польского, турецкого, китайского, японского, корейского, арабского — на английский, и с английского — на русский, украинский, немецкий, испанский, французский, итальянский, китайский, арабский (другие пары — через английский). «Вместо оригинала» или «Две строки». Обрывки одной фразы из соседних субтитров переводятся вместе, время и стиль не меняются. Модель (~165 МБ) скачивается один раз.
- **Маркеры на таймлайне.** **M** — поставить, **Shift+M** / **Ctrl+Shift+M** — к следующему / предыдущему, двойной щелчок — переименовать, правая кнопка — цвет. Клипы прилипают к маркерам. «Скопировать главы для YouTube» — готовый список `0:00 Вступление…` для описания, а при экспорте маркеры становятся главами внутри MP4.
- **Каталог плагинов.** «Настройки» → «Плагины» → «Каталог плагинов»: 14 новых переходов и эффектов с живым превью и установкой в один щелчок — полутон, кинескоп, масляная краска, карандаш, символы, «игрушечный город», блик объектива, рывок камеры, «один цвет», резкий сдвиг, разрыв бумаги, лучи света, кручение, ромбы. Файл `.glsl` можно просто перетащить в окно Kadro. Свой плагин можно прислать в каталог — [как](https://github.com/honeyjostar/kadro/blob/master/docs/PLUGINS.md#поделиться-и-прислать-в-каталог).
- **Сообщить об ошибке.** «Настройки» → «Помощь» или кнопка на экране сбоя: описание + версия, система и конец журнала (без личных путей, всё видно до отправки) → готовый отчёт на GitHub.

В 0.5.0 — 123 перехода-шейдера, эффекты-шейдеры, свои плагины на GLSL и «Ролик по сценарию». Полный список возможностей — в [README](https://github.com/honeyjostar/kadro#readme).
