## Kadro 0.3.0

Скачай **Kadro-Setup-0.3.0.exe** ниже и запусти. Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее → Выполнить в любом случае» (у установщика нет платной подписи). Обновление ставится поверх, проекты сохраняются.

### Новое
- **Видеоэффекты:** тряска, пульс, вспышка, глитч, RGB-сдвиг, VHS, зерно, виньетка, размытие, пиксели, зеркало, негатив, радуга — с регулировкой силы
- **Скорость:** кривые скорости (6 готовых и своя), реверс, стоп-кадр
- **Запись голоса** с микрофона прямо поверх видео
- **Цвет:** кривые, HSL по 8 цветам, свои LUT-файлы (.cube)
- **Ретушь лица:** сглаживание и осветление кожи
- **Группы** (составные клипы): Ctrl+G / Ctrl+Shift+G, в том числе с прозрачным фоном
- **Шаблоны:** 6 встроенных и свои

### Исправлено
- Экспорт падал, если на основной дорожке после склейки без перехода шла склейка с переходом
- Плеер надёжнее показывает нужный кадр сразу после перемотки
- Рамка выделения клипа больше не вылезает за пределы плеера

Полный список возможностей — в [README](https://github.com/honeyjostar/kadro#readme), руководство — [docs/GUIDE.md](https://github.com/honeyjostar/kadro/blob/master/docs/GUIDE.md).
