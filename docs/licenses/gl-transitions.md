# gl-transitions

Kadro включает переходы из библиотеки [gl-transitions](https://github.com/gl-transitions/gl-transitions) (npm `gl-transitions` 2.0.0).
Исходный код каждого перехода хранится как есть, вместе с заголовком об авторе и лицензии (`src/shared/gl/transitions.json`).
Переходы `DisplacementMap` и `LumaWipe` не включены: им нужны отдельные картинки-текстуры.
