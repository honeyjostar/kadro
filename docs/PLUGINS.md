# Плагины Kadro: свои переходы и эффекты

Переходы и эффекты в Kadro можно дописывать самому — небольшими файлами на **GLSL**, языке шейдеров
видеокарты (тот же, что в WebGL и в играх). Файл — это одна функция: она получает координату точки
кадра и возвращает её цвет. Kadro сам считает её для каждой точки каждого кадра — и в плеере, и при экспорте в MP4.

Кроме своих плагинов в Kadro уже встроены 123 перехода из открытой библиотеки
[gl-transitions](https://gl-transitions.com) (разделы «3D», «Глитч и ретро», «Зум и вращение», «Искажения
и огонь» и другие) и 6 эффектов-шейдеров (раздел «Эффекты» → «Шейдеры»). Их код — хорошие примеры.

## Каталог плагинов — установка в один щелчок

`Настройки` → `Плагины` → **Каталог плагинов**: переходы и эффекты сообщества с живым превью (наведи на
карточку — превью заиграет). **Установить** — и плагин сразу появится в «Переходах» или «Эффектах» →
«Плагины». Если файл в каталоге обновился, на карточке будет **Обновить**; корзина — удалить.

Свой файл `.glsl` можно поставить кнопкой **Из файла…** или просто **перетащить в окно Kadro** — Kadro сам
поймёт по тексту, переход это или эффект, и положит файл в нужную папку.

Каталог лежит в репозитории Kadro, в папке [`community-plugins`](../community-plugins): Kadro скачивает
`index.json` и сами шейдеры и сверяет каждый файл по SHA-256. Шейдеры работают только внутри видеокарты
(WebGL) — к файлам и сети у них доступа нет.

## Куда класть файлы

`Настройки` → `Плагины` → **Открыть папку плагинов**. Откроется `%USERPROFILE%\.kadro\plugins`:

```
plugins\
  transitions\   ← переходы (*.glsl)
  effects\       ← эффекты (*.glsl)
  examples\      ← примеры: перенеси файл в transitions\ или effects\, чтобы включить
  README.txt
```

Сохранил файл — Kadro подхватит его **сразу**, без перезапуска: переход появится в разделе «Переходы» →
«Плагины», эффект — в «Эффекты» → «Плагины». Ошибка в шейдере показывается в настройках (с номером строки),
остальная программа работает как обычно.

## Переход

```glsl
// Name: Диагональная шторка
// Author: Твоё имя
// License: MIT
// Description: Мягкая шторка из левого верхнего угла
// Tags: wipe
// @range(0.01, 0.5) Мягкость края
uniform float softness; // = 0.1

vec4 transition(vec2 uv) {
  float d = (uv.x + (1.0 - uv.y)) * 0.5;
  float m = smoothstep(progress * (1.0 + softness) - softness, progress * (1.0 + softness), d);
  return mix(getToColor(uv), getFromColor(uv), m);
}
```

| Что есть в переходе | Значение |
|---|---|
| `uv` | координата точки: (0, 0) — левый нижний угол, (1, 1) — правый верхний |
| `progress` | ход перехода: 0 — только первый клип, 1 — только второй |
| `ratio` | ширина кадра / высота (для круглых фигур: `uv.x * ratio`) |
| `getFromColor(uv)` | цвет первого (уходящего) клипа в точке |
| `getToColor(uv)` | цвет второго (приходящего) клипа |

Это формат [gl-transitions](https://gl-transitions.com/gallery): **любой переход оттуда можно скопировать в
файл как есть** (кроме тех, которым нужны картинки-текстуры).

## Эффект

```glsl
// Name: Сепия с виньеткой
// Author: Твоё имя
// License: MIT
// Description: Тёплый старый снимок с затемнёнными углами
// @range(0, 1) Виньетка
uniform float vignette; // = 0.6

vec4 effect(vec2 uv) {
  vec4 c = getColor(uv);
  float g = dot(c.rgb, vec3(0.299, 0.587, 0.114));
  vec3 sepia = vec3(g * 1.07, g * 0.87, g * 0.68);
  float v = 1.0 - vignette * smoothstep(0.35, 0.75, distance(uv, vec2(0.5)));
  return vec4(mix(c.rgb, sepia * v, amount), c.a);
}
```

| Что есть в эффекте | Значение |
|---|---|
| `uv` | координата точки клипа (как у перехода) |
| `getColor(uv)` | цвет клипа в точке (после цветокоррекции и встроенных эффектов) |
| `amount` | сила эффекта 0…1 — ползунок во вкладке «Эффекты» справа |
| `time` | секунды от начала клипа (для движения) |
| `progress` | 0…1 — где мы внутри клипа |
| `ratio` | ширина / высота клипа |
| `resolution` | размер клипа в пикселях (`vec2`) — например, чтобы взять соседний пиксель: `1.0 / resolution` |

Эффект применяется к самому клипу — до положения, поворота и маски: двигается и масштабируется вместе с ним.

## Заголовок и параметры

- Строки `// Name:`, `// Author:`, `// License:`, `// Description:`, `// Tags:` — название и описание в
  интерфейсе (можно по-русски). Без `Name` название берётся из имени файла.
- `uniform float имя; // = 0.5` — параметр со значением по умолчанию. Поддерживаются `float`, `int`, `bool`,
  `vec2`, `vec3`, `vec4`, `ivec2…4`: `uniform vec2 center; // = vec2(0.5, 0.5)`.
- `// @range(0, 1) Подпись` строкой выше параметра `float` — у эффекта появится ползунок с этой подписью.

## Как это работает при экспорте

FFmpeg шейдеры не выполняет, поэтому при экспорте Kadro рисует кадры с плагинами сам (тем же кодом, что и в
плеере) и вклеивает их в видео. Экспорт роликов с шейдерами поэтому чуть дольше: переход в полсекунды — это
15 кадров, эффект на весь клип — все кадры клипа.

## Если что-то не так

- **Плагина нет в списке** — проверь, что файл лежит в `transitions\` или `effects\`, расширение `.glsl`, а
  в «Настройках» → «Плагины» нет ошибки.
- **Ошибка «Нет функции vec4 effect(vec2 uv)»** — эффект должен называться `effect`, переход — `transition`.
- **ERROR: 0:12: …** — ошибка в строке 12 файла (так пишет компилятор видеокарты). GLSL строгий: `1.0`, а не `1`
  для чисел с плавающей точкой.
- Проект с плагином открыли на другом компьютере без этого файла — вместо перехода будет растворение, вместо
  эффекта — ничего. Положи файл в ту же папку — всё вернётся.

## Поделиться и прислать в каталог

Плагин — это один текстовый файл. Его можно просто прислать другу: он перетащит файл в окно Kadro.

Чтобы плагин появился в **каталоге** у всех:

1. Сделай форк [honeyjostar/kadro](https://github.com/honeyjostar/kadro) и положи файл в
   `community-plugins/transitions/` или `community-plugins/effects/`. Имя файла — латиницей
   (`my-cool-wipe.glsl`), оно же станет id плагина — не меняй его потом, иначе у людей сломаются проекты.
2. В заголовке обязательно: `// Name:`, `// Author:`, `// License:` (MIT, BSD, CC0 — чтобы его можно было
   распространять с Kadro), `// Description:` — одна фраза по-русски, что видно на экране. У параметров с
   `@range` — понятная подпись.
3. Выполни `npm run plugins:index` — пересоберётся `community-plugins/index.json` (названия и SHA-256).
4. Пришли pull request. Тесты проверят, что шейдер разбирается, заголовок на месте и список совпадает с файлами.
